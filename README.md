# HR Analytics Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **HR Analytics Dashboard** developed using Microsoft Power BI to analyze employee attrition, demographics, income, job satisfaction, and workforce trends.

The dashboard is designed to help HR teams and business leaders understand employee turnover and identify patterns that may contribute to attrition.

## 🎯 Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Employees | 1,470 |
| Employees Left | 237 |
| Attrition Rate | 16.12% |
| Average Monthly Income | $6,503 |
| Average Age | 37 |
| Average Years at Company | 7 |

## 🔍 Dashboard Analysis

### Executive Summary

The Executive Summary page provides an overview of employee attrition across:

- Departments
- Job roles
- Age groups
- Overtime status

### Employee Insights

The Employee Insight page explores attrition in relation to:

- Educational field
- Marital status
- Gender
- Job satisfaction
- Monthly income by department

## 📈 Key Insights

- The overall employee attrition rate is **16.12%**.
- The dashboard shows differences in attrition across departments and job roles.
- Younger employee groups show higher attrition compared with some older age groups.
- Overtime status is associated with differences in employee attrition.
- Attrition varies across educational fields and marital-status groups.
- Job satisfaction levels show differences between employees who stayed and those who left.
- Monthly income varies considerably across departments.
